# 🌾 Farming Scheduler APK

## 🧠 Introduction

The **Farming Scheduler** is an Android-based application designed to help farmers **automate reminders for spraying fertilizers and irrigating crops**. This system reduces the need to manually track schedules and helps improve agricultural productivity by ensuring timely farm operations.

⏱️ It also includes a **day-counting feature** to calculate the number of days between two spray schedules and alerts farmers with notifications, along with the fertilizer details to be used.

---

## 🔍 Existing System Drawbacks

| Problem Area             | Limitation in Current Practice                  |
| ------------------------ | ----------------------------------------------- |
| Manual Scheduling        | Farmers have to remember spray/irrigation dates |
| Human Error              | Forgetting leads to crop damage                 |
| No Automation            | No alerts or notifications                      |
| No Date Calculation Tool | Days between sprays counted manually            |

---

## ✅ Proposed System

* 🧠 Reminds farmers about spray and irrigation schedules
* 📅 Calculates days between two spraying events
* 💬 Sends alert messages with specific fertilizer information
* ❌ No more need for manual tracking or note-taking
* 🔢 Accurate technical date-based calculation built-in

---

## 🎯 Scope of the System

* 📱 **Target Audience**: Farmers in local areas
* 🌍 **Accessibility**: Available for all Android users
* 💼 **Two-in-One Services**: Spraying and irrigation reminders in a single app

## 📦 Modules

### 👨‍🌾 Farmer Module

* **View Scheduling**: See upcoming spray/irrigation alerts
* **Delete Scheduling**: Remove a schedule if not needed

### 🛠️ Admin Module

* **Manage Farmers**: View and delete farmer accounts
* **Manage Suggestions**: View, add, and delete user suggestions
